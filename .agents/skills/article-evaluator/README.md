# 文章阅读价值评估 · 使用说明

先打分拿结论，需要细节再追问。本页是**追问速查表**。

## 第一步：发起评估

发链接或正文，任选一种说法：

```
帮我打分
值不值得读
评价这篇文章
这篇是不是大厂水文 / 追热点？
```

## 你会先收到什么（简报）

约 15 秒读完，**5–6 行**：

```
🟡 **68 分 · 值得阅读 · 文章标题**

读的价值结论：值不值得读、为什么。

**Wiki 增量**（相对你的知识库）
- 🆕 **本文新增**：wiki 里还没有的概念或实践
- ♻️ **你已了解**：与 wiki 某篇重叠的内容（附 wiki 标题或链接）

追问「展开评分」「给摘要」「梳理名词」「展开 wiki 对比」「推荐文章」看细节。
```

评估时会**自动搜你的 wiki**，判断这篇文章有多少是新知识、多少你已经了解过。**不会**自动收藏或归档。

| 分数 | 含义 |
|------|------|
| 🟢 ≥80 | 强烈推荐阅读 |
| 🟡 60–79 | 值得阅读 |
| 🟠 40–59 | 选择性阅读（可能只读部分） |
| 🔴 <40 | 不建议阅读 |

## 追问速查表

**你问什么，才做什么。** 首次评估不会提前做这些。

| 你可以说 | 你会得到 |
|----------|----------|
| **展开评分** / 为什么 / 怎么打的 | 五维分数表、各维理由、红旗、文章画像 |
| **给摘要** / 讲什么 / 读哪部分 | **先整体**（背景→核心→要点），**再分段展开**；🟠 标注值得读/可跳过 |
| **展开 wiki 对比** | 相关 wiki 路径 + 逐条新/重复对照 + 阅读建议 |
| **能学到什么** | 能学到的 / 学不到的（结合 wiki 增量） |
| **梳理名词** / 陌生知识点 / 行话什么意思 / 读前先搞懂概念 | 提取术语 + 搜 wiki 对比 | 名词速查表：🆕 口语解释 + ✓ 指向 wiki |
| **推荐文章** | **此时才联网** + wiki 复查，1–3 篇外部替代/补充 |
| **完整报告** / 保存评估 | 汇总；可选写入 `wiki/evaluations/` |

### 组合追问示例

```
展开评分
给摘要
梳理名词
推荐文章
```

也可以连着问：

```
展开评分，再给摘要
推荐文章，要替代原文的
```

## 评估后还可说

| 你说 | 效果 |
|------|------|
| 收藏这篇文章 | 写入 `wiki/inbox/`，附上评分 |
| 归档 | 移入 `wiki/articles/` 并更新索引 |

## 五维打分（展开评分时才看）

| 维度 | 权重 | 关心什么 |
|------|------|----------|
| 见识增益 | 30% | 能否打破认知、增长见识（你最关心） |
| 知识密度 | 25% | 废话多不多 |
| 原创深度 | 20% | 一手洞察 vs 搬运/追热点 |
| 可验证性 | 15% | 有没有数据、代码、可复现 |
| 实践迁移 | 10% | 能不能用到工作里 |

详细锚点见 [rubric.md](rubric.md)。

## 脚本说明

| 脚本 | 用途 | 何时用 |
|------|------|--------|
| `collect.py <url> --fetch-only` | 抓取正文，**不写入 wiki** | **评估文章时** |
| `collect.py <url>` | 抓取并保存到 `wiki/inbox/` | 用户说「收藏」时 |
| `collect.py <url> --archive` | 抓取并保存到 `wiki/articles/`（slug 幂等） | 用户说「归档」且要直接入库时 |
| `archive.py <inbox路径>` | inbox → articles/（slug 幂等） | 用户说「归档这篇文章」时 |
| `search.py "关键词"` | 搜索 wiki 已有文章 | **评估时**（新/已有对比）+ 追问「推荐文章」 |

**评估 ≠ 收藏 ≠ 归档。** 你说「帮我打分」时，只读正文、出简报，不会往 wiki 里写任何文件。

```
发链接 → 「帮我打分」→ 看简报决定读不读
         ↓ 想读但时间紧
       「给摘要」→ 先整体认知（背景+核心+要点），再分段展开
         ↓ 术语太多看不懂
       「梳理名词」→ 口语化搞懂行话，对照 wiki 看哪些是新词
         ↓ 决定不读
       「推荐文章」→ 找更好的同主题阅读
         ↓ 值得收藏
       「收藏这篇文章」
```

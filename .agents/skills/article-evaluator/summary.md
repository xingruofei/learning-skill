# 追问：内容摘要

**触发**：给摘要、讲什么、读哪部分、这篇文章在说什么

**目的**：帮用户**不读原文也能懂大意**——先建立整体认知，再按需展开细节。

## 写作结构（两段式，顺序不可颠倒）

```
① 整体认知：背景 → 核心论点 → 要点提炼
② 分段展开：（可选）按章节/逻辑块逐段说明
```

**关键**：不是「只写整体」或「只写分段」，而是**先有整体，再有分段**。读者扫完①就能懂大意；需要细节或决定读哪节时，再看②。

| 块 | 写什么 |
|----|--------|
| **背景** | 行业/问题现状：大家在做什么、卡在哪、作者为何写这篇 |
| **核心论点** | 1–2 句：作者的核心判断或主张 |
| **要点提炼** | 3–5 条 bullet：全文精华，跨章节合并去重 |
| **分段展开** | 按文章逻辑块逐段 1–2 句；🟠 标注「值得读 / 可跳过」 |

**篇幅**：
- **🟢🟡**：① ≤300 字；② 覆盖主要章节，每段 1–2 句
- **🟠**：① 仍写全；② 只展开有价值段落，跳过部分标注「可跳过」；① 或 ② 末尾加 **读哪部分**（1 句）
- **🔴**：只写 ①（背景 1 句 + 核心 1 句说明为何不值得读），不写 ②

## 执行步骤

1. 通读全文，先写 ①：**背景 / 核心 / 要点**（回答「为什么写、主张什么、记住什么」）
2. 再写 ②：按章节或逻辑块分段，每段提炼 1–2 句（不是翻译目录，是这段**新增了什么信息**）
3. 🟠 在 ② 标注哪些段值得读、哪些可跳过；必要时补 **读哪部分**

## 输出模板

```markdown
## 内容摘要

**背景**：[2–4 句]

**核心论点**：[1–2 句]

**要点提炼**：
- [要点 1]
- [要点 2]
- [要点 3]

### 分段展开

**[段名/章节名]**：[1–2 句这段讲什么、信息增量在哪] <!-- 🟠 可加：值得读 / 可跳过 -->

**[下一段]**：…

<!-- 🟠 可选 -->
**读哪部分**：[1 句跳读建议]
```

## 写作要求

- **整体先行**：① 必须完整输出；禁止跳过背景直接从分段开始
- **分段是补充**：② 展开细节，不与 ① 要点简单重复；同观点在 ① 已概括，② 只补该段的论据/案例/方法
- **口语化**：像转述给朋友，少用「本文指出」「综上所述」
- **诚实**：数据/案例缺出处时标注「文中未给来源」

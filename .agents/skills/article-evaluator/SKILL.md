# 文章阅读价值评估

**核心任务：判断这篇文章值不值得读。** 结合 wiki 已有知识，区分「新信息」与「已了解过的重复内容」。

默认立场：**时间有限，宁可漏读不可误读。**

## 核心原则

```
首次：读文 → 搜 wiki 对比 → 打分（含增量判断）→ 简报
追问：才执行对应动作（按需 Read 下方参考文件）
```

**评估 ≠ 收藏 ≠ 归档。** 不写 wiki，除非用户明确说「收藏」「归档」。

---

## 首次 vs 追问

| 模块 | 首次评估 | 用户追问时 |
|------|----------|------------|
| 读全文 | ✅ `--fetch-only` 或用户正文 | 复用，不必重读 |
| **搜 wiki 对比** | ✅ **必做** | 「展开 wiki 对比」→ 详列路径和重叠点 |
| 心算五维 → 总分 | ✅（见识增益须考虑 wiki 增量） | — |
| 读的价值结论 | ✅ 输出 | — |
| Wiki 增量（新增 + 已有，各一行） | ✅ 输出 | — |
| 五维表格 / 红旗 / 画像 | ❌ | 「展开评分」→ [rubric.md](rubric.md) |
| 内容摘要 / 章节定位 | ❌ | 「给摘要」→ [summary.md](summary.md) |
| 能学到什么（展开） | ❌ | 「能学到什么」 |
| **梳理名词/知识点** | ❌ | 「梳理名词」→ [glossary.md](glossary.md) |
| **联网搜外部文章** | ❌ | 「推荐文章」 |
| 完整报告 / 存档 | ❌ | 「完整报告」「保存评估」 |
| 写入 wiki | ❌ | 「收藏」「归档」 |

### Wiki 对比（首次必做）

1. 提取文章 2–3 个主题关键词
2. `python scripts/search.py "<关键词>"` 或 grep `wiki/`（含 inbox、articles、notes）
3. 读匹配文章的 `summary` / 核心观点（有则读，无则跳过）
4. 判断：
   - **🆕 新**：wiki 未覆盖的概念、框架、实践
   - **♻️ 已有**：与 wiki 某篇重叠的观点（点名路径或标题）
5. **见识增益打分必须反映增量**：wiki 已充分覆盖 → 降分；全是新主题 → 可加分

**无匹配时**：`🆕 **本文新增**：暂无同题，对你大概率是新信息`；`♻️ **你已了解**：无重叠`

## 五维打分（心算，追问才展开）

| 维度 | 权重 | 评什么 |
|------|------|--------|
| **见识增益** | 30% | 相对 **wiki 已有**，能否新增认知 |
| **知识密度** | 25% | 有效信息占比 |
| **原创深度** | 20% | 一手洞察 vs 搬运/追热点 |
| **可验证性** | 15% | 数据、实验、代码 |
| **实践迁移** | 10% | 能否用到工作里 |

| 总分 | 建议 |
|------|------|
| ≥ 80 | 🟢 强烈推荐阅读 |
| 60–79 | 🟡 值得阅读 |
| 40–59 | 🟠 选择性阅读 |
| < 40 | 🔴 不建议阅读 |

wiki 高度重复：见识增益 ≤ 4，总分通常 ≤ 55。红旗 ≥2 条再降一档。

**展开评分**时 Read [rubric.md](rubric.md)，输出五维表 + 红旗 + 画像。

## 默认输出：简报

**≤220 字，5–6 行：**

```markdown
[🟢/🟡/🟠/🔴] **XX 分 · [阅读建议] · [文章标题]**

[读的价值：值不值得读、为什么，≤40 字]

**Wiki 增量**（相对你的知识库）
- 🆕 **本文新增**：[wiki 未覆盖的概念/实践，≤35 字]
- ♻️ **你已了解**：[与 wiki 重叠的内容，≤35 字]（[wiki 标题简称](path) 或「无重叠」）

追问「展开评分」「给摘要」「梳理名词」「展开 wiki 对比」「推荐文章」看细节。
```

### 简报规则

- 必须回答：**值不值得读** + **相对 wiki 的增量**
- **Wiki 增量**块必须有标题行，让读者一眼知道这是在对比个人知识库，不是文章目录
- 子项用 **本文新增** / **你已了解** 标签，禁止只写 🆕/♻️ 符号堆内容
- 无重叠写 `♻️ **你已了解**：无重叠`；wiki 无同题写 `🆕 **本文新增**：暂无同题，对你大概率是新信息`
- wiki 来源尽量带链接或标题简称，勿只写「Harness文」之类缩写
- **禁止**首次：五维表、完整摘要、外部推荐、写文件、联网搜索
- **禁止**无 `--fetch-only` 的 collect.py

示例见 [examples.md](examples.md)。

## 评估原则

- **读的价值第一**：分数服务于「要不要花时间读」
- **增量优先**：wiki 已覆盖的内容不算见识增益
- **诚实**：只有标题时声明置信度低
- **懒加载**：追问才 Read 参考文件；外部搜索、详细摘要等同理
